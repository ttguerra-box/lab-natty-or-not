# Criando imagens ultrarrealistas utilizando a MetaAI no Whatsapp

## 📒 Descrição
Criar imagens ultrarrealistas utilizando a ferramenta MetaAI integrada ao aplicativo WhatsApp

## 🤖 Tecnologias Utilizadas
MetaAI e WhatsApp

## 🧐 Processo de Criação
Foi tentado uma diversidade de prompts, desde os mais simples, aos mais elaborados, para criação de imagem pela ferramenta.

## 🚀 Resultados
Para geração de imagens mais realistas, é necessário o uso de prompts mais elaborados e detalhistas. Caso contrário, o algoritmo pula detalhes, revelando que a imagem foi gerada por IA.

## 💭 Reflexão (Opcional)
Há uma necessidade enorma de prompts mais elaborados, detalhando imagens para geração de imagens mais realistas..
